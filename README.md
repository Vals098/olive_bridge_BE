# OliveBridge
Backend for OliveBridge, a B2C & B2B e-commerce platform connecting Italian EVO oil producers with the Japanese market.

## About
OliveBridge is a web platform designed to connect one Italian extra virgin olive oil producer with customers and business buyers in Japan.
The platform supports both B2C and B2B interactions, including product browsing, online orders, user accounts and business inquiries.

## Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Spring Security
- JWT

## Frontend
The frontend is developed separately with:
- React
- TypeScript
- Vite
- Bootstrap
